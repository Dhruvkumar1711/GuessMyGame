# 💗 Guess My Crush's Number

A small, fun browser game where you try to guess your crush's secret number between **1 and 10**.

You get **3 chances** to guess the number correctly. Maybe it's just a random number... or maybe your hearts are actually in sync. 👀

## 🌐 Live Demo

**[Play Guess My Crush's Number](https://guessmygame.vercel.app/)**

## ✨ About the Project

I built this project as a simple JavaScript practice project to work with:

- DOM manipulation
- JavaScript functions
- Event listeners
- Random number generation
- User input validation
- Conditional logic
- Dynamic UI updates
- Basic responsive design

The idea is intentionally simple, but the goal was to make the experience feel more playful and interactive rather than just building a basic number guessing game.

## 🎮 How to Play

1. Think about your crush. ❤️
2. Enter a number between **1 and 10**.
3. Click **Guess**.
4. You have **3 attempts**.
5. Use the hints to help you.
6. Guess the correct number and see what destiny has to say. 💕

## 🚀 Running Locally

Clone the repository:

```bash
git clone <your-repository-url>
```

Move into the project folder:

```bash
cd guess-my-crush-number
```

Then open `index.html` in your browser.

No backend or installation is required.
